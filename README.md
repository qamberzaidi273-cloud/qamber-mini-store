# React Starter Hub

Theek hai! Chaliye shuru karte hain **Stage 1: React project open karna StackBlitz par**.



**Step 1: StackBlitz kholein**

Apne mobile browser (Chrome ya koi bhi) mein yeh link kholein:

👉 https://stackblitz.com



**Step 2: Naya project banayein**

- Sign up/login karein (Google/GitHub account se easy hai)

- Home page par "Create Project" ya "+" button dhoondein

- Search box mein type karein: **"Vite"**

- Templates mein se **"React"** wala template choose karein (icon: ⚛️, naam kuch is tarah hoga "React" ya "Vite + React")



**Step 3: Project open hone dein**

- Tap karne ke baad StackBlitz automatically ek naya React project bana dega

- Thoda wait karein (10-30 seconds), phone par ek code editor + preview screen dikhegi



**Step 4: Confirm karein**

Jab project khul jaye, aapko yeh dikhna chahiye:



- Left side: File list (src, public, package.json, waghera)

- Right side: Ek chhota sa React demo page ("Vite + React" likha hua, counter button ke saath)



---



**Ab aap yeh karein:**

1. Upar diye gaye steps follow karke project banayein

2. Jab preview screen par "Vite + React" wala demo dikh jaye, mujhe bata dein "Ho gaya" ya screenshot share kar dein



Iske baad hum **Stage 2** mein project ke files samjhenge, phir apna store banana shuru karenge. 🙂
